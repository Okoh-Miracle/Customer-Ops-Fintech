# Fintech Customer Operations Platform

A polished fintech customer-operations prototype for managing support tickets, SLA risk, customer context, knowledge workflows, QA reviews, escalations, and operational audit events.

**Live demo:** https://okoh-miracle.github.io/Customer-Ops-Fintech/

## What this demonstrates

- Ticket intake and operational triage
- Intent and priority classification
- SLA monitoring and queue prioritization
- Customer context and support history
- Knowledge-base assisted resolution
- Escalation and specialist routing
- QA review workflows
- Operational audit logging
- Search and filtering across support operations

## Run locally

No build step is required.

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project note

The interface and records are a demonstration environment using synthetic customer and support data. It is not connected to any bank, payment processor, or production support system.
